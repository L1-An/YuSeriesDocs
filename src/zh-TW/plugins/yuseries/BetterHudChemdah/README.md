## 關於

> 支援版本: 1.12 - 1.21

BetterHudChemdah 是一款基於 **TabooLib 6.2** 開發的 Chemdah 對話系統擴展插件，
專為提供更加豐富和沉浸式的對話體驗而設計。通過與 BetterHud 的深度集成，
為玩家帶來視覺效果更佳的對話界面和交互體驗。

## 特色

- **沉浸式對話體驗**: 結合虛擬攝影機技術，提供電影級對話視覺效果
- **BetterHud 深度集成**: 完全基於 BetterHud 的 Popup 系統構建對話界面
- **智能對話管理**: 支持動態文本顯示、分頁回覆和滾輪選擇
- **豐富的 Kether 動作**: 擴展 Chemdah 腳本系統，提供攝影機控制、旁白等功能
- **任務追蹤系統**: 集成任務追蹤界面，提供更好的任務導航體驗
- **高度可配置**: 所有界面元素、音效、動畫都可以完全自定義
- **多主題支持**: 靈活的主題系統，支持不同風格的對話界面
- **性能優化**: 基於事件驅動架構，確保流暢的遊戲體驗
