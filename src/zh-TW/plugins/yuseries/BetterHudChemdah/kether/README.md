# 動作概覽

BetterHudChemdah 為 Chemdah 提供了多種 Kether 動作來增強對話體驗。每個動作都有其特定的功能和使用場景。

## 動作分類

### 攝影機控制
- **[camera](camera.md)** - 控制沉浸式對話中的虛擬攝影機位置和設定

### 界面增強  
- **[narration](narration.md)** - 顯示旁白文字到玩家屏幕
- **[dialog](dialog.md)** - 控制對話標題和頭像的動態設定

### 功能擴展
- **[bhquest](bhquest.md)** - 管理任務追蹤顯示功能
- **[goto-self](goto-self.md)** - 重新打開當前對話以刷新狀態
