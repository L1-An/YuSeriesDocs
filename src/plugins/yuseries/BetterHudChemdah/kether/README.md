# Action Overview

BetterHudChemdah provides various Kether actions for Chemdah to enhance dialogue experience. Each action has its specific function and use case.

## Action Categories

### Camera Control
- **[camera](camera.md)** - Control virtual camera position and settings in immersive dialogue

### Interface Enhancement  
- **[narration](narration.md)** - Display narration text on player screen
- **[dialog](dialog.md)** - Control dynamic settings for dialogue titles and avatars

### Function Extensions
- **[bhquest](bhquest.md)** - Manage quest tracking display functionality
- **[goto-self](goto-self.md)** - Reopen current dialogue to refresh state
